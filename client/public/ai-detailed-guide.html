神经网络 (Neural Network)

深度学习的基石，由相互连接的神经元组成

📊 工作流程
输入数据 → 加权求和 → 激活函数 → 输出传递 → 反向传播 → 权重更新

详细步骤解析

1
输入层接收数据
原始数据（如图像像素、文本编码）进入网络的第一层
x = [x₁, x₂, x₃, ..., xₙ]
2
加权求和
每个神经元将输入与权重相乘后求和，加上偏置项
z = Σ(wᵢ × xᵢ) + b
3
激活函数
通过非线性函数引入非线性，使网络能学习复杂模式
a = σ(z) = 1 / (1 + e^(-z)) # Sigmoid示例
4
前向传播
数据逐层传递，直到输出层产生预测结果
Input Layer → Hidden Layer 1 → Hidden Layer 2 → Output Layer (784) (256) (128) (10)
5
计算损失
比较预测结果与真实值的差异
Loss = Σ(y_pred - y_true)² / 2 # 均方误差
6
反向传播
计算梯度，将误差从输出层传回输入层
∂L/∂w = ∂L/∂a × ∂a/∂z × ∂z/∂w
7
权重更新
使用梯度下降优化权重
w_new = w_old - α × ∂L/∂w

核心特性

非线性映射能力
能学习任意复杂函数
并行计算
可高效利用GPU加速
自适应学习
自动调整参数优化性能
泛化能力
能处理未见过的数据

代码示例 (PyTorch)

import torch import torch.nn as nn # 定义神经网络 class NeuralNetwork(nn.Module): def __init__(self, input_size, hidden_size, num_classes): super(NeuralNetwork, self).__init__() self.fc1 = nn.Linear(input_size, hidden_size) self.relu = nn.ReLU() self.fc2 = nn.Linear(hidden_size, num_classes) def forward(self, x): x = self.fc1(x) x = self.relu(x) x = self.fc2(x) return x # 创建网络实例 model = NeuralNetwork(784, 256, 10) # 训练过程 for epoch in range(100): outputs = model(inputs) loss = criterion(outputs, labels) optimizer.zero_grad() loss.backward() optimizer.step()

Transformer

革命性的注意力机制架构

📊 工作流程
输入嵌入 → 位置编码 → 多头自注意力 → 残差连接&层归一化 → 前馈网络 → 输出

核心机制：注意力

注意力计算公式
Attention(Q,K,V) = softmax(QK^T / √d_k) × V

Q=查询, K=键, V=值。通过计算Q和K的相似度，加权聚合V的信息。

详细步骤解析

1
输入嵌入
将词汇转换为高维向量
E = Embedding(x)
2
位置编码
为序列添加位置信息
PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
3
多头自注意力
从多个角度捕捉信息关系
MultiHead(Q,K,V) = Concat(head₁,...,head₈)W
4
残差连接与层归一化
稳定训练，加速收敛
LayerNorm(x + Sublayer(x))
5
前馈神经网络
每个位置独立的全连接网络
FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

class CNN(nn.Module): def __init__(self): super(CNN, self).__init__() # 第一层卷积 self.conv1 = nn.Conv2d(1, 32, 3, padding=1) self.pool = nn.MaxPool2d(2, 2) # 第二层卷积 self.conv2 = nn.Conv2d(32, 64, 3, padding=1) # 全连接层 self.fc1 = nn.Linear(64 * 7 * 7, 128) self.fc2 = nn.Linear(128, 10) def forward(self, x): x = self.pool(F.relu(self.conv1(x))) # 28x28 -> 14x14 x = self.pool(F.relu(self.conv2(x))) # 14x14 -> 7x7 x = x.view(x.size(0), -1) # 展平 x = F.relu(self.fc1(x)) x = self.fc2(x) return x

RNN / LSTM

序列数据处理专家

📊 RNN工作流程
输入序列 → 时间步1 → 传递隐藏状态 → 时间步2 → ... → 时间步N → 输出

RNN vs LSTM

特性 RNN LSTM
长期依赖 ❌ 困难（梯度消失） ✅ 优秀
门控机制 无 遗忘门、输入门、输出门
细胞状态 无 有（直接传递信息）
参数量 少 多（约4倍）

LSTM门控机制

遗忘门：决定丢弃哪些信息
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
输入门：决定存储哪些新信息
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
细胞状态更新
C_t = f_t × C_{t-1} + i_t × C̃_t
输出门：决定输出什么
o_t = σ(W_o · [h_{t-1}, x_t] + b_o), h_t = o_t × tanh(C_t)
