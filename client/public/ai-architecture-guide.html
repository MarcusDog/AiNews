Transformer 架构
Attention Is All You Need (2017)
Transformer是一种基于注意力机制的深度学习架构，彻底改变了自然语言处理领域。它完全摒弃了RNN和CNN，只使用注意力机制来捕捉输入序列中的全局依赖关系。
Transformer 工作流程详解
1
输入嵌入 (Input Embedding)
将输入的词汇转换为高维向量表示。每个词被映射为一个固定长度的向量，包含了词的语义信息。
"你好" → [0.2, -0.5, 0.8, ..., 0.3] # 512维或768维向量
2
位置编码 (Positional Encoding)
由于Transformer没有循环或卷积结构，需要显式添加位置信息。使用正弦和余弦函数为每个位置生成独特的编码。
PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
3
多头自注意力 (Multi-Head Self-Attention)
核心机制！让序列中的每个位置都能关注到其他所有位置。使用多个注意力头从不同角度捕捉信息。
Attention(Q,K,V) = softmax(QK^T/√d_k) × V
其中 Q=查询, K=键, V=值
4
前馈神经网络 (Feed Forward)
每个位置独立应用相同的前馈网络，通常包含两个线性变换和ReLU激活函数。
FFN(x) = max(0, xW₁ + b₁)W₂ + b₂
5
层归一化与残差连接
每个子层后都应用层归一化(Layer Normalization)和残差连接，帮助梯度流动并加速训练。
Output = LayerNorm(x + Sublayer(x))
6
编码器-解码器结构
编码器：处理输入序列，生成上下文表示
解码器：基于编码器输出和已生成内容，逐步生成目标序列
💡 关键创新点
  • 自注意力机制：能直接建模序列中任意两个位置的关系，无论距离多远
  • 并行计算：不像RNN需要顺序处理，可以高度并行化，训练速度快
  • 可扩展性：容易扩展到非常大的模型和数据规模
  • 多头注意力：从多个角度学习不同的特征表示
🎯 实际应用
  • GPT系列：仅使用解码器，从左到右生成文本
  • BERT：仅使用编码器，双向理解文本
  • T5：同时使用编码器-解码器，适合翻译和摘要
  • Vision Transformer：将图像切分为patches，应用Transformer处理图像

CNN 卷积神经网络
Convolutional Neural Network
CNN是专门处理具有网格结构数据（如图像）的神经网络。通过卷积操作自动提取局部特征，并通过池化减少计算量，是计算机视觉的基石。
CNN 工作流程详解
1
卷积层 (Convolution Layer)
使用卷积核（滤波器）在输入图像上滑动，提取局部特征如边缘、纹理、形状等。每个卷积核学习检测特定的特征。
输入: 32×32×3 (RGB图像)
卷积核: 5×5×3
输出特征图: 28×28×N (N个滤波器)
2
激活函数 (Activation)
引入非线性，让网络能学习复杂的模式。ReLU是最常用的激活函数。
ReLU(x) = max(0, x)
负值归零，正值保持不变
3
池化层 (Pooling)
降低特征图的空间尺寸，减少计算量和参数量，同时保持主要特征。最大池化取区域内的最大值。
Max Pooling (2×2):
[1, 3; 2, 4] → [4]
尺寸减半，通道数不变
4
堆叠多层
重复卷积-激活-池化操作，逐渐提取更高级、更抽象的特征。浅层学习边缘，深层学习整体形状和物体部分。
5
全连接层 (Fully Connected)
将提取的特征展平并映射到最终的分类输出。每个神经元与前一层的所有神经元相连。
展平: 7×7×512 → 25088维
全连接 → 4096 → 4096 → 1000 (分类数)
6
Softmax输出
将输出转换为概率分布，所有类别的概率和为1。
🔑 CNN 核心特性
  • 局部连接：每个神经元只连接输入的局部区域，减少参数量
  • 权重共享：同一卷积核在整个输入上共享权重，提高效率
  • 平移不变性：物体在图像中位置变化时仍能识别
  • 层次化特征：浅层学习简单特征，深层学习复杂组合

RNN / LSTM 循环神经网络
Recurrent Neural Network / Long Short-Term Memory
RNN适合处理序列数据（如文本、时间序列），具有记忆能力，能利用历史信息。LSTM是RNN的改进版，解决了长期依赖问题。
RNN 工作原理
1
循环结构
RNN的核心是循环连接：当前时刻的输出不仅依赖当前输入，还依赖前一时刻的隐藏状态。
h_t = tanh(W_hh × h_{t-1} + W_xh × x_t + b)
y_t = W_hy × h_t + b
2
时间展开
将RNN按时间步展开，形成深层网络结构。但这也导致了梯度消失/爆炸问题。
LSTM 门控机制详解
1
遗忘门 (Forget Gate)
决定从细胞状态中丢弃哪些信息。使用sigmoid函数输出0-1之间的值。
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
2
输入门 (Input Gate)
决定哪些新信息存储到细胞状态中。包含sigmoid层（决定更新哪些值）和tanh层（创建候选值）。
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)
3
更新细胞状态
将旧状态乘以遗忘门结果，加上新候选值乘以输入门结果。
C_t = f_t × C_{t-1} + i_t × C̃_t
4
输出门 (Output Gate)
决定输出什么值。基于细胞状态，但经过一个过滤。
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
h_t = o_t × tanh(C_t)

🔗 LangChain
LLM Applications
核心优势
• 链式调用：组合多个组件形成工作流
• 工具集成：搜索引擎、数据库、API
• 记忆功能：维护对话上下文
• RAG支持：检索增强生成
核心概念
Chains: 组合LLM和提示的序列
Agents: 自主决策使用工具的LLM
Memory: 持久化对话历史
Retrieval: 从外部数据检索
Tools: 外部功能调用
from langchain import OpenAI, LLMChain, PromptTemplate from langchain.memory import ConversationBufferMemory # 创建提示模板 template = """你是一个AI助手。 历史对话: {history} 人类: {input} AI:""" prompt = PromptTemplate( input_variables=["history", "input"], template=template ) # 添加记忆 memory = ConversationBufferMemory( memory_key="history") # 构建Chain llm = OpenAI(temperature=0) chain = LLMChain( llm=llm, prompt=prompt, memory=memory ) # 运行 response = chain.predict("你好")
